This is the NLP-based AI Grammar and Spelling correction project, as part of group project for Simbolo's AI Level 1 Class. 
The theme of this project is educational and we aimed to resolve grammar and spelling, targeting upto B2 level ESL students. This project aims to start as the foundation of grammar and spelling correction and to expand into advanced levels in terms of corrections and capabilities of this work, and even the language to our mother tongue - Myanmar.
